# Pokedex-App

The **Pokedex-App** is a small web application built using HTML, CSS, and JavaScript that loads data from an external API and enables the viewing of data points in detail.

## Project Overview

This project consist of a Pokedex of Pokemon and their details as well as a portrait of each. Users can also search for items and access the app across several platforms.

## Features

**Feature #1:** Load data from an external source (API).

**Feature #2:** View a list of items.

**Feature #3:** On user click, they can view the details for that item.

## Project Dependencies

**jQuery**

## Setup and Installation

     To run the app locally:

     1. **Clone the Repository**:
        ```bash
        git clone https://github.com/Malave615/Pokedex-app
        ```

     2. **Install Dependencies**:
        ```bash
        npm install
        ```

     3. **Visit Deployed App Site**:
        https://malave615.io/Pokedex-app/

## Testing

     1. Code Linting:  npx eslint ./js
     2. Code Formatting:  npx prettier --check
     3. Manual testing in the browser with the Developer Toolbar
